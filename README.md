# 台灣用語翻譯機（轉換中國用語）— 簡繁轉換 & 台灣用語 Chrome 擴充功能

自動將網頁上的簡體中文轉為繁體中文，並將常見中國用語轉換為台灣用語。

## 功能

- **簡體 → 繁體**：逐字轉換頁面上所有簡體字
- **中國用語 → 台灣用語**：如「软件」→「軟體」、「视频」→「影片」、「鼠标」→「滑鼠」等
- **動態頁面支援**：透過 MutationObserver 監聽 SPA / 無限捲動新增的內容
- **一鍵開關**：點擊工具列圖示直接切換啟用/停用，無彈出視窗，無需重整頁面；停用時圖示顯示紅色 ✕ badge

## 安裝方式（開發者模式）

1. 開啟 Chrome，前往 `chrome://extensions/`
2. 右上角開啟「**開發人員模式**」
3. 點擊「**載入未封裝項目**」
4. 選取本專案資料夾（`China2Taiwan_dict/`）

## 圖示說明

`icons/` 目錄中需要有以下 PNG 圖示：
- `icon16.png`（16×16）
- `icon48.png`（48×48）
- `icon128.png`（128×128）

可使用 `icons/icon.svg` 轉換，或使用任何圖示工具產生。

## 詞典擴充

- **新增中國用語詞彙**：編輯 `dict_tw.js`，在 `CHINA_TO_TW` 物件中加入 `"中國用語": "台灣用語"` 即可
- **新增簡繁對照**：編輯 `opencc_data.js`，在 `SIMP_TO_TRAD` 物件中加入 `"簡": "繁"` 即可

## 執行測試

本專案使用 Jest 進行單元與整合測試。

```bash
npm install
npm test
```

測試涵蓋：

- `content.js` 簡繁轉換、詞彙替換、長文字分段處理

## 隱私權政策

請參閱 `PRIVACY_POLICY.md`。本擴充功能不會收集個人識別資料，所有轉換均在本地完成。

## 權限說明

本擴充功能使用以下權限：

- `<all_urls>`：內容腳本需要讀取與修改網頁上的文字，才能將簡體中文轉為繁體中文，並將中國用語轉換為台灣用語。
- `file:///*`：允許在本地 HTML 檔案上執行相同轉換（需使用者另行開啟「允許存取檔案網址」）。

本擴充功能不會讀取或傳輸任何個人資料、密碼、表單內容或瀏覽紀錄至外部伺服器。
